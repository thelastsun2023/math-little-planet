# 口算小星球

直接打开 `index.html` 即可使用；全部资源在本地，无需联网、安装依赖或构建。

## 规则
- 六种模式，每次随机生成 20 题（允许重复）。包含 0；加法的两个数与结果均不超过模式上限，20以内和100以内减法结果必须大于0。10以内乘法两个数为1–10。100以内除法被除数不超过100、除数大于0、答案为正整数，无余数。
- 数字键输入答案；也可以用运算符输入表达式，遵循先乘除后加减。无需执行任何动态代码。
- 按 = 判分；空输入或未完成表达式不计分。判分后本题锁定，点击显示屏继续。
- 按「答案」立即显示答案并记错。已判分的题不能再次计分或更改。
- 完成 20 题后统计题数及比例。更换模式或重新开始会清空本轮数据；不收集个人信息。
- 支持键盘数字、运算符、Enter 核对、Backspace 退格、Delete 清除；判分后空格进入下一题。

## Android 封装
HTML、CSS、JavaScript 分离，使用相对资源路径，没有外部字体、CDN、服务器接口或模块加载。可将三个文件复制到 Android assets，以 WebView 加载本地 index.html，并开启 JavaScript；也可放入 Capacitor 的 webDir 目录。没有依赖设备权限。正式封装时在 Android 项目中处理系统返回键与窗口安全区即可。

界面通过 viewport 和触摸按钮适配手机；练习数据仅保存在内存，重新加载会重置。

## 中英文语音
支持中文/English/静音，自动读题、判分反馈及完成提示，可手动重读。使用浏览器 SpeechSynthesis API，无外部音频资源。实际声音及离线能力取决于系统语音包；不支持的浏览器会提示并保持文字练习正常。Android WebView 对此 API 支持因设备而异，封装时建议用 Android TextToSpeech 原生桥接替换 speak 函数，安装中文和英文离线语音包。

答对题在语音结束后1秒自动跳题；静音时直接等待1秒。答错和查看答案需点击屏幕。每题用时从出题至判分，整轮总时间包含语音和等待；结果页提供每题明细。顶部模式按钮为单行横向滑动。
